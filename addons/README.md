# StampKitPanel: manual-mode FreeCAD addon for StampKit.

Install (Windows):

    scripts\install_freecad_addon.py

which copies this directory into `%APPDATA%\FreeCAD\Mod\StampKitPanel` and
verifies the bootstrap. Set the STAMPKIT_SRC environment variable (or edit
Init.py) to point at the StampKit repository's `src` directory.
